# Effects Vocabulary

> **Purpose** — canonical reference for writing card effects across the database.
> Every card must use vocabulary defined here. If a card needs a verb or pattern
> not listed, add it here first, then write the card.
>
> **Style rule** — terse verb + number, optionally followed by 🌀
> if the effect scales with combo. "Sap 3🌀" not "Sap 3 multiplied by combo".

---

## Combo notation — 🌀

When an effect scales with the combo formula, append 🌀 to the value:

| Notation | Meaning |
|---|---|
| Sap 3 | Sap exactly 3, no combo scaling |
| Sap 3🌀 | Sap (3 × current combo value) |
| Poison 1🌀 | Apply (1 × combo) poison stacks |

The 🌀 symbol indicates "this number multiplies by combo."

## Core verbs

These are the only verbs allowed on player and tower cards.
Add new ones to this section before using them on a card.

### Sap N

Reduce target enemy's Zeal by N.
Default target: based on tower priority field, or "target enemy" for actions.

### Poison N

Apply N poison stacks to target enemy.
Stacks decrement by 1 each turn (3 stacks → 3+2+1 = 6 total Zeal sapped).
Ignores shield.

### Push N

Move target enemy N tiles backward along the path.
If pushed past the path entry, Sap N where N is the remaining tiles to push.

### Restore N

Restore N land integrity. Place removed desolation tokens back on quadrants.
Restore targets the most-eroded active quadrant by default unless specified.

### Silence N

- **Silence (tower) N** — target tower cannot trigger effects for N turns.
- **Silence (totem) N** — target totem cannot trigger effects for N turns.
Specify which when writing the effect.

### Slow N

Reduce target enemy's speed by N for 1 turn.
If speed reaches 0 or below: enemy does not move.
**Frozen** is Slow equal to enemy's full speed.

### Burn

Apply burning status to target. Burning enemies lose 1 Zeal per turn for 1 turn.
Re-applying refreshes duration.

### Remove N

Permanently remove N cards from your hand or discard pile.
Removed cards leave the game for this scenario.
No on_discard effects trigger.

### Reveal N

Show N cards from your hand to all players. Cards return in hand.
Used by skills and conditional triggers.

### Draw N

Draw N cards from your deck. If deck is empty, no effect (no mid-turn reshuffle).

### N🪙

Generate N buy energy. Resets at end of turn.
Reminder: never generated by discarding for play energy — only when card is played.

### XP N

Grant N XP to a player. Used by contract rewards and rare card effects.

### Remove N (card)

Permanently remove a card from your hand or discard pile.
Useful to trim decks.

### Barrier N

place N barrier tokens on a quadrant.
When desolation tokens would be placed on that quadrant,
remove a barrier token instead. One barrier blocks one desolation.
Barrier tokens persist until consumed or the quadrant is Ravaged.

## Enemy-specific verbs

These appear on enemy cards only.

### Erode N

Place N desolation tokens on the quadrant the enemy currently occupies.
If desolation reaches resilience threshold: quadrant is Ravaged.

### Ravage N

Reduce global resilience by N permanently.
Cannot be recovered within a scenario. Bosses only (typically).

### Summon N

Reveal the next N cards from the wave deck immediately.
Place revealed enemies at the start of the path.

### Embolden N

At end of turn, if no Sap was applied to this enemy this turn, gain N Zeal.
Forces players to maintain pressure on Emboldened enemies every turn.

### Bury (totem)

Permanently reduce totem capacity by 1. Group chooses which totem is removed
unless the boss card specifies otherwise. Bosses only.

### Discard (card)

Players collectively discard N cards.
They do not re-draw before their next turn.

## Conditional patterns

The standard syntax for conditional effects.
In the final printed version of the cards, we will use logos as placeholders.

### Combo threshold

```text
If combo ≥ N → effect
```

Used on cards that reward deep combos. Threshold scales with tier.

### Element match

```text
If element is water → effect
If first card played → effect
```

Used to gate effects to specific build types or moments.

### Status check

```text
If target is poisoned → effect
If target is burning → effect
If target is slowed → effect
```

Used for setup-payoff cooperative play. Lives in `status_triggers:` field.

### Board state

```text
If no enemies on path → effect
If quadrant is Ravaged → effect
If totem zone has X totems → effect
```

Used by conditional totems and rare powerful cards.

### Player count / position

```text
If you played 3+ cards this turn → effect
If you have not bought a card this wave → effect
```

Used to reward specific play patterns.

### "Instead" pattern

```text
If target is poisoned → Sap 6 instead
```

Replaces the base effect entirely. Used in `status_triggers:` field.
The "instead" keyword is mandatory for clarity — without it, players will assume the effects stack.

### "Additional" pattern

```text
If combo ≥ 4 → also apply Poison 2
```

Adds to the base effect. The "also" keyword is mandatory for clarity.

## Tier balance ranges

Numerical guidance per tier. These are starting values for playtesting,
not locked rules. Adjust during balance passes.

### Tier 1 (early game, cost 1-3🪙)

| Effect    | Range    |
|---        | ---      |
| Sap       | 1–3      |
| Poison    | 1        |
| Push      | 1        |
| Restore   | 1        |
| Slow      | 1        |
| Draw | not allowed |
| Remove | not allowed |
| 🪙 generated | 1–2 |
| Conditional bonus | +1 to +2 |

### Tier 2 (mid game, cost 3-5🪙)

| Effect | Range |
|---|---|
| Sap | 3–5 |
| Poison | 2–3 |
| Push | 1–2 |
| Restore | 2 |
| Slow | 1–2 |
| Draw | 1, conditional preferred |
| Remove | 1, conditional |
| 🪙 generated | 2–4 |
| Conditional bonus | +2 to +4 |

### Tier 3 (late game, cost 5-8🪙)

| Effect | Range |
|---|---|
| Sap | 5–8 (often conditional or scaling) |
| Poison | 3+ or scaling formulas |
| Push | 2–3 |
| Restore | 3+ |
| Slow | 2+ |
| Draw | 1–2, conditional |
| Remove | 1–2 |
| 🪙 generated | 4–6 |
| Conditional bonus | +3 to +6 |
| Scaling formulas | combo-based, totem-based |

> **Loop risk flag** — any tier 2+ card combining Draw + 🪙 generation on `on_discard`
> must be marked `loop-risk: true` for Claude Code playtesting agents.

## Element archetypes

Each element has thematic verb affinities. Cards should respect their element's
identity — a water card with primarily fire/burn effects breaks the build-engine logic.

### Water

**Theme:** flowing, persistent, dissolving
**Primary verbs:** Sap, Poison, Push (waves)
**Signature pattern:** stacking damage over time, displacement, status effects
**Avoid:** Burn, Reinforce (water doesn't fortify)

### Leaves

**Theme:** growth, spread, regeneration
**Primary verbs:** Restore, Poison (spores), spreading status effects
**Signature pattern:** per-turn ticks, status propagation to adjacent enemies
**Avoid:** Push, raw Sap (leaves heal and infect, they don't strike)

### Ground

**Theme:** solid, defensive, breaking
**Primary verbs:** Reinforce (TBD), shield-piercing Sap, AoE
**Signature pattern:** durability, counter-attack, Ravage protection
**Avoid:** subtle status effects, fast triggers

### Air

**Theme:** movement, speed, reveal
**Primary verbs:** Slow, Reveal, Push, Draw
**Signature pattern:** disruption, information, mobility
**Avoid:** raw damage, persistent status effects

## Cooperative pattern templates

These are patterns specifically designed to reward cross-player play.
Include at least one of each across the card set.

### Setup card (apply status without resolving payoff)

```yaml
effect: Apply 2 poison stacks to target enemy.
note: Designed for ally to exploit via status_triggers.
```

### Payoff card (rewards setup by another player)

```yaml
effect: Sap 3.
status_triggers:
  poisoned: Sap 6 instead       # rewards a teammate's poison setup
  burning: Sap 5 and Push 1     # rewards a teammate's fire setup
```

### Combo extender (helps multiple players hit thresholds)

```yaml
effect: Reveal 1 card. If it shares any active hero's element, draw it.
note: Indirectly helps all heroes reach combo thresholds.
```

### Resource sharer (transfers economy across players)

```yaml
effect: Choose another hero. They gain 2🪙.
note: Lets DPS heroes feed support heroes' Burrow access.
```

## Forbidden patterns

These patterns are banned across the entire card set.

- **Lock-and-key effects** — "Only works on flying enemies" with no flying counter elsewhere
- **Hard counters to single archetype** — "Cancels all combo bonuses" without recourse
- **Forced losses** — effects that auto-fail the wave with no player agency
- **Untargeted mass status** — "All enemies become Emboldened" with no scaling logic
- **Discard punishment** — "If you discard this, lose 5 Zeal" — breaks the discard engine
- **Hero elimination** — heroes can be exhausted but never permanently removed

### Combo notation — 🌀

The 🌀 symbol may only follow values for these verbs:
- Sap, Poison, Push, Burn, Slow, Reveal, Restore, Barrier

🌀 may NOT follow:
- 🪙 generation
- Draw
- Remove
- XP grants

## Naming conventions

- Card names: 2-4 words, evocative, lore-consistent
- Avoid generic verbs in names: "Strike", "Attack", "Hit"
- Prefer concrete imagery: "Croc Roll", "Swamp Gas", "Tide Surge"
- Hero-specific cards may reference the hero's identity
- Lore tone: serious without taking itself seriously

### Slug format

File reference uses lowercase-hyphenated:

```text
name: Croc Roll
slug: card:croc-roll          # auto-generated, not written
```

## Effect resolution order on a played card

When a card's `effect` resolves, apply in this order:

1. **Base effect** as written (Sap N, Poison N, etc.)
2. **status_triggers** check — does target's status modify the effect?
3. **terrain_affinity** check — does the current quadrant terrain modify?
4. **Combo bonuses** — apply combo formula multipliers from totems
5. **on-play effects** trigger any "after a card is played" totems

Status_triggers using "instead" replace step 1 entirely — terrain and combo
still apply on top

## Default values

If a field is not explicitly defined, it is considered null / not applicable for this card.

Exception: fields where omission could be ambiguous must always be declared.
- `loop-risk` — always declare if true, omit if false
- `requires_facing` — always declare on tower cards
- `tier` — always declare (no meaningful default), except in starting decks.
- `cost` — always declare (0 would be a meaningful value), except in starting decks.
