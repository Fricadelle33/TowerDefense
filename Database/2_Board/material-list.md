## Notes

- **Hex tile quantities** depend on the largest scenario's path layout. To be determined once scenarios are written.
- **Card quantities** depend on final card set size per hero and market.
- **Neoprene mat size** is approximate — exact dimensions depend on hex tile size (25mm) × grid resolution (16×16 per quadrant).
- Print-on-demand targets: [The Game Crafter](https://www.thegamecrafter.com), [MakePlayingCards](https://www.makeplayingcards.com)
