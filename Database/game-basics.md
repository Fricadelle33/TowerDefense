# Game concepts

### Abstract
This game is an asymmetrical cooperative tower defense board game with deck building mechanics and character leveling up. 

### Means to an End
This project is intended for printing, this project serves as a digital proof of concept. 

### Theme / Lore
This game is set in a world resembling Earth, where animal heroes face waves of world-destroying enemies. To prevent them from ravaging the world, heroes must unite and repell them. 

### Global innards and sinew
This tower defense heavily relies on combo mechanics to defeat waves of increasingly challenging foes : engine building ; multipliers and scaling ; and synergies inside the deck and between players.  

### Inspiration
- Board games: Aeon’s End, Imperium: Legends, Dead Cells, Hero Realms, Spirit Island (for hero meta)
- Video games: Balatro, Black Jacket, Monster Train, Slay the Spire, Dead Cells 

### Gameplay
Players choose an animal hero with its own starting deck, favorite terrain(s), mechanics, etc. To face ever bigger enemies, they can buy cards from the market and unlock new cards – shared or player-specific – by completing contracts or kicking out elite mobs. 

### Game modes
This game is intended to be first played in campaign mode, with a set of pre-written scenarios. Then, players can design their own.
