# Lore

## Elements

This game relies on four elements used for combos and lore : Water, Leaves, Ground and Air.

## Elemental Names

~~~yaml

    Undines
    Nereids
    Merenneito
    Sedna       # Inuit sea goddess
    Ahti        # Finnish sea ruler
  leaves:
    Dryad
    Treant
    Satyrs
    Tapio       # Finnish forest god
    Mielikki    # Finnish forest huntress
  earth:
    Gnomes
    Hulder
    Landvættir  # Icelandic land spirits
  air:
    Sylphs
    Thunderbird # Sioux
  non-elemental:
    Wakinan     # Sioux
    Haltija     # Finnish household / nature spirits
    Kami        # Japanese
~~~
