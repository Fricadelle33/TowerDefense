# Game Setup

## Players
2 to 4 players. Each player chooses a hero and takes their hero card,
starting deck, and Burrow deck.

---

## New scenario
### Board and path
- Draw a scenario card
- Setup the path as indicated by the scenario card

### Wave deck
- **Reveal** next wave card — read wave composition and bonus
- **Build** next wave deck — shuffle standard and elite cards face-down
- **Prepare** meeples — assign one meeple per enemy card
- **Begin** next wave

### Totems
- **Shuffle** the totem deck and place it in the appropriate location

### Heroes
- **Shuffle** hero decks and draw the named cards, or number of cards, indicated by hero:starting_deck
- **Set** hero XP to 0

### Maintenance
- Place all tokens somewhere reachable
